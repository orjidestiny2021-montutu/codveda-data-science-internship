# Codveda-Data-Science-Internship
This repository contains the complete collection of tasks and projects completed during my Data Science Internship at Codveda. The internship program is structured to progressively build skills from foundational data handling to advanced machine learning and natural language processing techniques.
The tasks are divided into three levels, each focusing on a specific set of data science competencies. 

### Level 1 - Data cleaning & EDA
This level focuses on the essential first steps of the data science pipeline: preparing raw data for analysis and uncovering initial insights.

#### Level 1 Task 2 - Cleaning
This task involves handling missing values, removing duplicates, correcting data types, and addressing outliers to create a clean, reliable dataset.

#### Level 1 Task 3 - EDA
Using statistical summaries and visualizations to understand data distributions, identify patterns, and discover relationships between variables.

### Level 2 - Regression & Classification
This level introduces core supervised machine learning algorithms for predictive modeling.
#### Level 2 Task 1 -
Regression: Building and evaluating models to predict continuous numerical values (e.g., price prediction) using techniques like Linear Regression, Decision Trees, and Random Forests.

#### Level 2 Task 2 -
Classification: Developing models to categorize data into discrete classes (e.g., spam detection, customer churn) using algorithms such as Logistic Regression, K-Nearest Neighbors (KNN), and Support Vector Machines (SVM).

### Level 3 - Time Series & NLP
The advanced level covers specialized domains of data science: sequential data analysis and text processing.

#### Level 3 Task 1 - Time Series Analysis: Analyzing data points collected over time to identify trends, seasonality, and patterns, often for the purpose of forecasting future values.

#### Level 3 Task 2 - NLP (Sentiment Analysis): Applying Natural Language Processing techniques to text data to determine the sentiment (positive, negative, or neutral) expressed in user reviews, comments, or social media posts.
